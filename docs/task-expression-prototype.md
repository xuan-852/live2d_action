# 任务驱动的连续身体表达功能测试

2026-11-13。用户授权更大幅度动作，并直接测试北极星功能。当前交付是任务/内部状态 → 表达计划 → 实际SDK执行 → 反馈调整的可运行骨架；上层是明确的规则基线，尚无自由文本理解、生成模型或学习优势认证。

## 输入与职责

`TaskExpressionDirector` 接收 `{id,purpose,targets,request,confidence}`。purpose为inspect/compare/emphasize/wait/cancel；targets为场景身份序列。请求文本用于显示，语义目的和对象由调用方明确给定，不是从文本自动推断。拒绝未知对象、额外参数字段、非法时间/置信状态和重复ID。

任务不携带执行器值、动作帧表或预排的目标切换时刻。规则层发出表达计划，并消费实际反馈推进：目标要连续15帧满足实际位置、收停、手指和视线；原生指向还需材料轴对固定对象≤6°。未满足时不因播放时长结束就算完成。失败后报告受限、下调规则置信状态并改变文字/脸部候选，转向任务给定的下一对象；这不是自主发明新目标，也不是学习。

空间路线/节点仍由下层执行，不修改外部请求位置来掩盖失败。本轮是有deadline的点任务连接，不宣称保留了某条未提供的运动路线。已有双臂、头身、手指、视线和脸部反馈接口复用，无新网络、模型拓扑、纹理或SDK修改。

## 场景与更大动作

- A：右侧固定对象[.59,.28]，复用已知原生臂点姿态作为节点起点。
- C：上方固定对象[-.12,.65]，复用原MMD第28帧已研究的高位腕/肘要求（腕约[.1222,.5061]）作为节点请求。两对象在求解前固定，不事后移到手指射线上。现有五轴标定与Core求解只校正掌平面朝向，交给实际SDK重新验收；不是重做参数扫描。
- E：原生臂与补丁臂共同展开的候选。补丁沿用已认可腕点与既有几何保护，三角度[-38,18,-4]仅用于构造节点，不直接绕过控制器。手形中性，无缩掌/剪切/新增指形；没有保证这就是可信的对照手势。
- U：明确超范围的腕[.12,.95]、肘[.13,.65]和对象[.12,1.05]，原请求保留，用来检查实际残差、限制、退让和恢复，不伪造执行成功。

`DialogueBody` 的本地场景登记扩展为可选双侧arms、gesture和reachSeconds，旧native nodes登记仍可用；超时退让检查所有活动侧的实际位置和收停。置信状态只影响上层候选文字/脸部，不是力度标量，不缩小全部动作或更改执行预算。

## 固定测试与结果

最终36秒、30Hz，1080个控制帧＋1初始化帧，SDK原物理持续开启。7个外部任务事件在1/361/385/409/481/751/991帧输入；事件是用户改变任务，不是预排的内部动作阶段。首任务A→C→E、后面的到位保持与目标切换都由实际反馈决定。

本轮三次完整SDK采集均保留：session-01是独立恢复指令的首轮；session-final改为同任务实际失败触发恢复；session-wide仅扩大取景。共3243个SDK配对帧，不覆盖前版。

最终结果：6个目标取得连续15帧实际达标，2个目标因外部改令明确中断，U保留受限。首次A/C/E均取得实际保持；移动中C→A后取消，不续播旧目标。U在16.033秒开始，17.867秒依据实际反馈报告受限；同任务17.900秒选择C，20.633秒完成保持，中间没有新外部指令。U任务最终仍为limited，没有用C成功覆盖U失败。最后15帧身体/手指/视线/脸部均收稳。

实际连续性与几何：无本轮actual连续性越界报告，独立SDK节点与通道应用值核对差0，Core/渲染配对差0，补丁最小三角面积比.636166、翻转0、恢复误差0。原生最大节点步长.054868模型单位、补丁.010893；补丁腕相对起点最大位移.14636模型单位。所有量都是模型坐标，不是米或人体力矩。

限制不能忽略：原生99帧limited（最长1.867秒），补丁37帧limited（最长.433秒），包含局部求解约束、截止时间未收稳/超时、边界和U残差等；不是全任务均按原deadline完成。原生无分支符号变化；补丁在208/263/799/857帧经过近伸直位置，弯曲角符号连续跨0，四次变化均记录，不能写成无换支或用无网格翻转冒充自然。完整原因计数在task-assessment.json。
