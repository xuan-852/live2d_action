# 实测有效旋转中心：第一轮

用户要求以实验获得真实响应节点，不再凭截图/旧常量猜轴。关联K05/K07/K08/K10。暂停上层训练与v0节点定版。

证据`E:/FuXuanLab/runs/20261109-effective-pivot-measurement-02/`：protocol、冻结脚本、raw-mesh-responses.npz、results.json、REPORT.md。同模型MOC，Core默认参数，每次reset后单独干预9个候选参数的-6/-3/-1/+1/+3/+6，SDK物理关闭。保存所有网格原始响应，可离线复核。不是全参数重扫。

正交Procrustes拟合2D刚体变换，解(I-R^T)c=t求有效中心。±1/±3中位数中心，±6检查外推稳定性；每网格要求各幅度旋转角≥.05度、运动RMS>1e-5、刚体拟合残差/运动<.02、中心最大偏差<.003模型单位。门槛为实验条件，不是解剖/视觉认证。2项已知轴心正负旋转/纯平移测试后总48项通过。

结果：Param99多个手网格中心约(.186866,.036923)，偏差约1e-6–1e-5；ParamAngleZ脸ArtMesh128中心约(0,.419211)，偏差约1.0e-6。Param97前臂/手多个网格约(.120790,.202980)，偏差约.00115，门槛通过但弱于腕/头侧倾。Param94无网格通过固定中心稳定性：例如ArtMesh238刚体残差很小，但中心最大偏差.01314。BodyAngleZ2同样中心偏差约.00534，不通过。不能将低刚体残差等同固定中心存在。

AngleX/Y无通过网格；不证明没有转头俯仰，只说明该干预不能稳定解释为固定二维刚体旋转。BodyAngleX2只有ArtMesh143/144局部通过，不代表整个躯干轴心恢复，严禁用局部饰件推断全身。潜在原因含Live2D关键形状插值、平移/旋转耦合与真实非刚性；本轮没有区分这些机制，不据此判为模型缺陷。

这是**有效运动中心测量**，不是编辑器变形器轴/父子树恢复。没有认证肩节点，没有测新增补丁轴：Core不执行补丁变形，下一项必须在真实WholeArmSession上识别或明确代码定义，不能镜像原生点冒充实测。旧v0虚拟头胸根不由本结果继承。首轮-01结果相同但缺原始网格留存，-02补存原始证据后完整重复，结果一致。无Unity新动作录制，无提交推送。
