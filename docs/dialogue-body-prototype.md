# 对话身体表达原型

日期：2026-11-13。独立研究接口，未接生产桌宠或生产AI。

北极星：上层组织语言与连续身体表现，下层执行节点、方向、时间并反馈。当前交付把语义计划接到已有执行器：关注对象、文字发言期、姿态、视线、已有手形、脸部、打断、收回、限制降级能在一次SDK会话内运行。

## 结构和能力边界

- `tools/control/dialogue_body.py`：消费表达计划并保存当前计划、关注对象、发言截止时间、实际执行会话和降级状态。规则基线按意图/情绪组织身体，不是学习或自由文本语义理解。
- `tools/control/dialogue_plan.schema.json`：六字段计划协议。id、kind、text、target、affect、utteranceSeconds；拒绝未知字段、未登记对象、未知能力、重复ID和非法时间。模型或外部作者可提交同一结构，不能直接注入参数值或改场景能力。
- kind：listen/say/reference/think/decline/cancel。affect：neutral/warm/uncertain/firm。这些是输入意图与候选表现分支，不等于六种含义已获视觉认证。
- 场景登记A复用用户认可的第一项指向节点与手形；不是任意坐标逆解。B没有可用指向登记，返回具体限制，保留视线与文字，不伪造伸手成功。
- `BodyExecutionSession` 继续处理实际状态继承、头身连接、双臂目标与退出；原生/补丁执行器不重置。现在允许在线反馈provider同时使用原生手指和视线。
- `FaceController` 可选控制已有眼睑、嘴开合、嘴形、笑眼六通道，整帧速度3单位/秒、加速度18单位/秒²，消费SDK应用值；隔离Unity桥同时校验范围/速度/加速度。不是新美术、表情语义模型或音素口型。
- 发言期嘴部变化是文字时钟提示，没有音频，不叫口型同步。眼球值是二维作者输入，未保证三维视线精确瞄准。
- 发言结束后收回；取消立即接管；指向到期持续未满足位置/手指/视线或通道异常时，依据实际反馈降级并收回。

## 验证范围

26秒/30Hz一次持续会话，780控制帧＋1初始化帧。包含11个意图事件：倾听、指向A、倾听、说明、思考、再次指向、中途取消、换到B、保留判断、结束回应、退出。首版和最终版各781帧，无覆盖、无控制器重置。补丁保持中性、物理关闭，本轮未认证双臂自由组合、身体物理变化下稳定性、任意场景或生产实时延迟。

初始140项、最终151项单元测试均实跑通过。新增11项覆盖非法计划不替换当前计划、重复ID、对象能力降级、取消不续播、退出不反复重启、实际失败反馈降级、同时间不同输入改变决策、倾听少动、脸部实际状态连续与恢复等。两个中间测试导入/脚本修正记录保留。

最终SDK结果：11事件归属检查通过；取消后无旧指向；B明确降级；最后15帧身体/手指/视线/脸部收稳。独立JSON复核实际节点和手指/视线/脸部应用值最大差0，Core/渲染配对差0，补丁面积比1、翻转0。本例补丁没有运动，不能据此认证它的动态表达。

原生实际最大节点步长0.019266模型单位、速度0.577967单位/秒、加速度2.015027单位/秒²；帧级参数最大变化0.919968。指向保持窗口材料轴对A最大角差0.001219°，仅为已定义材料代理，不证明可见指尖/语义/真实视线。转换中保留11帧terminal-not-settled，不是全部阶段均到位。所有通道无本轮连续性异常报告，表达含义和自然度仍待用户完整录像审看。

第二个可选参数为UTF-8 JSON文件，包含events数组，每项为[动作帧,计划对象]。帧必须有序、唯一，范围1..780且从1开始。场景A/B能力由本地登记，输入不能覆写。自定义计划不继承内置场景专用的保持/取消窗口验收。

`session-final/dialogue-review.mp4`：26秒完整原图、请求/实际材料节点、场景标记与脸部近景、中文对话及限制。`dialogue-raw.mp4`为无叠加原图。视频没有重复静态样本充当动态或改动动作时间。

`dialogue-events.json`、`requested-packets.json`、`planner-history.json`、`sdk/track.jsonl`与PNG/JSON原帧保留输入、决策、请求、实际状态和失败。baseline含工作区状态、原差异与文件快照；final-files和task-only.diff保存本轮增量。未提交、推送、安装或下载。
