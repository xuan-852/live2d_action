# 对话计划到身体执行的离线原型（2026-11-13）

用户要求较大幅度推进整体表达，授权从任务和状态组织连续对话表现。接口、限制、复现见 [原型说明](../dialogue-body-prototype.md)。证据：`E:/FuXuanLab/runs/20261113-dialogue-body-01/`。

已验证：消费严格语义计划，按对象能力和实际反馈选择指向/少动/视线/脸部/退出；provider与手指、视线反馈同时工作。26秒11事件，最终781个配对SDK帧，取消不续播、B对象能力降级、末段所有通道收稳，独立实际节点与通道应用值核对差0。初始140、最终151项实跑通过。两次完整录制均保留，转换中11帧终端未收稳仍报告。

未认证：视觉含义与自然度、上层自由文本理解/生成、学习优势、音频同步、任意对象指向、双手手指、变化身体物理下表现。原生A是已认可指向的登记复用；补丁中性、物理关闭。不能因测试通过把规则样例称为自主表达，也不把眼球二维输入当精确三维视线。

新证据推进了语义计划与执行反馈之间的链路；尚未证明生成模型能从对话自行组织好身体。上次失败的解释手势和靠头手势没有重新引入，手掌无缩放/剪切。
