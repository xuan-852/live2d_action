# Live2D Action Lab

符玄 Live2D 动作探索独立仓库。

## 当前状态

本仓库目前只有项目骨架，尚未引入模型、Cubism SDK、Unity 工程或旧动作执行器。不能据此宣称已经能构建或播放动画。

首要目标是建立可靠、可独立运行的探索环境，再研究可读、连续的整体动作。桌宠主项目不作为编译、测试或运行依赖。

## 探索范围

- 模型能力测量、动作生成与基于画面关系的重定向。
- 原生手臂控制，以及用户补充的手臂/手部网格的持续改进。
- 肩部连接、上臂/前臂/手的协调、遮挡层序、变形质量与可达范围。
- 确定动作时间步的渲染、图像与状态配对、人工视觉评审。

不包含聊天、记忆、工具系统、桌面窗口、安装器或生产接入。暂不在旧主项目配置 submodule。

## 目录

| 路径 | 用途 |
|---|---|
| `docs/BOUNDARIES.md` | 工作边界与旧实现准入原则 |
| `docs/PLAN.md` | 分阶段启动计划与验收条件 |
| `runtime/` | 候选运行时，尚未实现 |
| `preview/` | 独立预览工程，尚未建立 |
| `tools/` | 动作、采集、评审工具，尚未实现 |
| `tests/` | 自动化测试与小型固定样例 |
| `assets/` | 经许可与来源检查后引入的资源 |

大规模录制、构建与中间产物放在仓库外。资源许可尚未核查，因此本次不发布模型、贴图或 SDK，也不默认给本仓库添加开源许可证。

## 开发入口

先读 `AGENTS.md`，再按当前任务读取直接相关文档。不默认加载旧桌宠项目历史。

当前唯一可运行的基础验证：

```powershell
python -m unittest discover -s tests -p "test_*.py"
```

该验证只检查仓库骨架，不验证动画能力。
