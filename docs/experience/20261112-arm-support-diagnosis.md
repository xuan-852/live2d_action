# 快档“飘带、无力量感”：过渡姿态与远端滞后定位

关联 K01/K02/K03/K04/K07/K08/K09。用户对[提速版](20261112-arm-speed.md)反馈：响应确实更快，但“像是被风吹起来的飘带，没有力量感”。这是快档视觉质量的负面反馈，不能继续以到位时间/无翻转/参数连续性宣称动作自然。上一轮对旧受限版未见明显问题的反馈仍有其版本边界，不转移到本轮快档。

**后续文献复核纠正**：[人体运动研究对照](20261112-arm-motor-literature.md)保留本页实际测量，但限制其解释：掌滞后、关节不同步或非单调本身不证明违反人体规律，首末关节关系相同也不自动要求中间不变；不得由此直接锁腕或统一相位。更明确的代码缺口包括截止时间仅用于报告、任务终端状态不完整，仍需同请求消融验证因果。

本轮只诊断，不改变控制器、速度档、目标、模型、绑定、SDK或上层组织。没有编排有力动作来冒充原因解释，没有训练/扫描。复用最近提供的 `E:/FuXuanLab/runs/20261112-arm-speed-01/point-fast/`，并明确不声称已穷尽其他录像的原因。新证据目录：`E:/FuXuanLab/runs/20261112-arm-support-diagnosis-01/evidence-verified/`。

## 已验证的实际执行现象

诊断来自同帧最终网格材料节点与应用执行器，而非理想链。这里的段朝向/相对弯角是二维材料几何量，不是经过认证的解剖关节角；原生 Param94/97/99 的数值也不是角度。

### 补丁侧：近端已抬，远端挂住，随后补折腕

点目标由 shoulder=-35/elbow=0/wrist=0 构造，首末姿态的肘/腕相对关系不变。实际过渡：

- 肘材料相对弯角临时偏离中性约 +11.91°；腕约 +24.29°，之后回到目标附近。返回阶段腕还反向临时折到约 -25.8°（补丁执行角）。
- 第 7 个控制样本，局部时间 .20 秒：上臂材料方向已转 -27.89°，约为最终 -35° 的 80%；掌方向只转 -3.15°，约为目标的 9%。
- 因而出现上臂先被搬动、掌方向长时间挂住，再靠手腕追上的关系。它与用户的飘带观感吻合；这不是“同一正确动作只是播放更快”。

### 原生侧：反向弯肘与多轴补偿也存在

- 最终材料肘弯变化约 +48.06°，起步却先走到约 -35.01°，然后反向追目标。
- 腕材料相对弯角临时变化约 -36.46°，最终又回到原关系附近。
- 同样在局部 .20 秒：上臂材料方向已变化 +41.41°，甚至超过最终约 +36.78°；掌方向却几乎未变（约 -.10°），最终需要变化约 +84.84°。
- 应用参数的回收也有大范围补偿：Param94 的目标从 18 回到 0，过渡中跑到约 -25.00；这是模型参数单位，不能写作 -25°。这些补偿仍可满足单帧速率上限，因此“无跳变/无换支异常”不能证明过程协调。

## 代码层原因与证据范围

`stateful_arm.py` 的单帧目标函数有两个明确缺口：

1. **不同任务未按语义/容差归一化。** 肘/腕使用位置残差，掌向使用长度约 .03 的掌向量弦误差；几项直接同权相加。初始实际请求中，位置平方代价/掌向弦平方代价分别约 67.6（原生）和 133.6（补丁）。这给先减位置误差、后补方向的路径留下明显偏好。该比值是本例任务代价，不是力量评分；单凭比值不能证明改一个权重就必然修好。
2. **约束了变化幅度，未定义过渡姿态协调。** 速度、加速度、停止前瞻和面积保护能排除部分跳变/几何失败，却没有约束本例过渡中肘腕关系如何演变，也没有明确限制不必要的反向补偿。位置终点、掌向和安全约束可以全部最终满足，中间仍能走出“先挂住、再甩过去”的过程。

本点目标仅给首末节点/方向和截止时间，未给完整中间路线；不能倒推它已经提供了某条应被严格保持的上层路线。应补的是下层可解释的姿态过渡/协调能力，而不是把任意新表演曲线冒充原请求。

**因果等级**：上述反向补偿、远端滞后、任务函数未归一化和缺少协调约束是已验证事实；它们能解释用户观感，但本轮没有通过单变量 SDK 消融证明哪一项是唯一主因，也没有证明新的控制器方案已经修好“力量感”。

## 排除与未证实项

- 这条证据 `physics=false`，全部实际帧 `physicsState=disabled`。除原生三轴之外的 SDK 参数均无可测动态变化。至少该片段不能归因于 SDK 风/物理振子；“像风吹”是观感，不是已发现风模拟。
- pairing/restore 最大误差均 0，不支持先解释为采集错帧。
- 到位后局部 1.0..1.77 秒的最大材料节点变化约为原生 1.46e-5、补丁 2.34e-7 模型单位。证据指向移动/收停关系，不是到位后持续漂移。
- 补丁上臂材料链长度变化约 .075%，前臂/掌段近常量；不能先把问题归为整条手臂大幅拉伸。不过材料链长度不能认证所有网格局部形变或美术接合。
- 头身在这条测试中固定，缺少身体承接可能影响整体观感，但未通过对照证明；不据此要求下层擅自添加身体表演。
- 不能凭当前证据认定必须改拓扑、重新猜腕点、加入完整三维骨骼/肌肉物理或把加速度继续放大。

## 下一步边界

保持已经改善的响应能力，优先解决中间肘腕关系、反向补偿与掌向滞后：明确位置/方向容差下的任务权重，并对有路线的输入保持路线；对只给终点的输入，使用清楚限定的姿态连接策略。本例可用同一首末目标检查是否减少临时肘腕折弯及近端/远端脱节，然后仍交用户看画面。不能把“一直锁腕/锁肘”推广成所有动作的默认，也不能把更多平滑或统一强度标量当作结论。
